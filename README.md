# Pandas DataFrame Operations

## Project Description

This project demonstrates the basic operations of the Pandas library using a custom dataset. It includes DataFrame creation, data exploration, filtering, grouping, sorting, handling missing values, creating new columns, summary statistics, and exporting data to a CSV file.

## Features

- Create a DataFrame using a custom dataset
- Display the first and last five rows
- View DataFrame information and data types
- Generate summary statistics
- Handle missing values
- Create a new column
- Perform Series operations
- Filter data based on conditions
- Group data and calculate mean values
- Sort data in descending order
- Apply boolean masking
- Remove duplicate and missing values
- Create a subset of selected columns
- Export data to a CSV file
- Calculate sum, mean, and standard deviation

## Project Files

- `pandas_operations.py` – Python source code
- `filtered_data.csv` – Output CSV file generated by the program
- `README.md` – Project documentation

## Requirements

- Python 3.x
- Pandas Library

## Installation

Install Pandas using the following command:

```bash
pip install pandas
```

## How to Run

Run the program using:

```bash
python pandas_operations.py
```

## Expected Output

The program displays:

- First and last five rows of the DataFrame
- DataFrame information
- Summary statistics
- Series operations
- Filtered DataFrame
- Grouped and aggregated data
- Sorted DataFrame
- Boolean masked DataFrame
- Total sum, mean, and standard deviation
- Creates the file `filtered_data.csv`
